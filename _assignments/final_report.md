# Overview

The final project report constitutes the main evaluable component of your semester project.  You should 
turn in the report via Gradescope.  While most people are working in pairs, you should turn in only 
**one** copy of the report.  Select one of your two group memebers to submit the report, and ensure that 
the name and student ids of both team members are included.

## Structure of the report

The report should follow the structure of a standard scientific paper.  Specifically, you should have an
**abstract**, and **introduction** (covering related / relevant work, and introducing the problem), a 
**methods** section (this will likely constitute the majority of your report) that describes, in detail, the 
methods you implemented, a **results** section that will explain the experiments you performed and the results
you observed and a **conclusion / discussion** section describing your overall conclusions and potential
future work.

Ensure that in your paper (ideally at the end of the abstract) you link to the relevant source code, which 
you should make available on GitHub.  The code can be private or public, but if it is in a private repo, please
ensure that you add Ali and I both to the repository.

As always, please ensure proper citation in both your report and your code, and include relevant citations
to any prior work off of which you are building, any existing tools you are using, and any code you are 
using in your project implementation.

## Format of the report

There is not a strict formatting requirement on the report, but I highly suggest using the Oxford Bioinformatics
template (available for [LaTeX](https://www.overleaf.com/latex/templates/oup-general-template/ybpypwncdxyb) or 
[Word](https://static.primary.prod.gcms.the-infra.com/static/site/bioinformatics/document/cabios-word-temp.zip?node=9b946b36faff1c196dba&version=541801:1bc4a5f5521ada3b11e7)).
In this format, your report should be 4-6 pages long (it should not be shorter, and should be longer only if absolutely necessary).
If you choose a different format, please ensure you include the sections listed above.  The length should
be similar (unless, e.g. you use a format with double spacing etc.).
